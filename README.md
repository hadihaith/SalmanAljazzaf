# 🌌 Dr. Salman Aljazzaf — Kuwait University

Welcome to the repository for the personal academic website of **Dr. Salman Aljazzaf** from **Kuwait University**, built using [Astro](https://astro.build/). 🚀

## ✨ About

This project is an Astro-based web page dedicated to Dr. Salman Aljazzaf, providing a platform to showcase his academic profile and related information.

## 🛠️ Built With

- 🚀 **[Astro](https://astro.build/)** — Web framework
- 💻 **HTML, CSS, and JavaScript** — Web development technologies

## ⚙️ Getting Started

### 📋 Packages

- [Node.js](https://nodejs.org/) installed on your machine
- npm (included with Node.js)

### 📥 Installation for local testing

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-directory>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### ▶️ Run Locally

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### 🏗️ Build for Production

Generate the production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
